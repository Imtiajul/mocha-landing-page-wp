== Description ==

AOSE Matcha is a modern hybrid block theme designed for matcha and wellness brands. It brings a soft, editorial Japanese tea garden aesthetic to WordPress with deep forest greens, subtle pink blossoms, vibrant lime accents, and elegant serif typography.

Key Features:
* Astra-Style Dynamic Header & Footer Builders: Customize Above Header, Primary Header, Mobile Drawer, Above Footer (Newsletter), Multi-Column Footer, and Below Footer (Copyright) dynamically in Appearance > Customize.
* 5 Dynamic Widget Areas: Main Sidebar, Header Widget Area, Footer Widget 1, Footer Widget 2, and WooCommerce Shop Sidebar.
* Layout & Container Controls: Container Max-Width slider (1000px - 1600px), Site Layout modes (Normal, Boxed, Full Width), and Sidebar Layout selectors for Default, Blog Archive, and Single Posts.
* Global Colors & Palette: Live Customizer color pickers for Primary Matcha, Accent Lime, Dark Forest, Light Mint, Blossom Pink, Body Ink, Link, and Link Hover colors.
* Full Typography Controls: Base font size & line-height sliders, plus individual font-size sliders for Headings H1 through H6.
* Blog & Single Post Settings: Grid (2/3 col) vs. List layouts, Excerpt lengths, Post Meta toggles (Author, Date, Category, Read Time, Comments), and Editorial Narrow single post reading width.
* Built-in Breadcrumb Trail: Accessible breadcrumbs with Schema.org BreadcrumbList structured data.
* WooCommerce Ready: Full storefront theme support, dedicated woocommerce.css, gallery zoom/lightbox/slider, and Matcha-styled product cards & cart/checkout tables.
* 100/100 Lighthouse Performance & SEO: Optimized WebP images (89% payload reduction), LCP preload, preconnect hints, canonical links, Open Graph, Twitter Cards, and Schema.org JSON-LD.
* RTL & Translation Ready: Complete rtl.css for right-to-left languages and languages/aose-matcha.pot translation template.
* Official Child Theme: Bundled aose-matcha-child ready for safe developer customizations.
* Zero Inline Styles: All design tokens, fluid clamp typography, and component layouts are cleanly organized in modern CSS layers.
* 100% Mobile Responsive: Perfectly tuned for small mobile (320px) up to 4K ultrawide displays.
* Elementor Compatible: Full support for Elementor page builder, Elementor canvas, and header/footer locations without styling conflicts.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes and click "Add New".
2. Click "Upload Theme" and select the aose-matcha theme zip file.
3. Click "Install Now" and then "Activate".
4. To edit the homepage visually, navigate to Appearance > Editor (Site Editor).
5. To configure header and footer layouts dynamically, navigate to Appearance > Customize.
