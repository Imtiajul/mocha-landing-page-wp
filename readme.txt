A serene, editorial, production-ready WordPress block theme for matcha wellness brands, crafted with fluid clamp typography, responsive layouts, modular block patterns, and full Elementor compatibility.

== Description ==

AOSE Matcha is a modern Full Site Editing (FSE) block theme designed for matcha and wellness brands. It brings a soft, editorial Japanese tea garden aesthetic to WordPress with deep forest greens, subtle pink blossoms, vibrant lime accents, and elegant serif typography.

Key Features:
* Full Site Editing (FSE): Seamless customization with block templates and template parts.
* Zero Inline Styles: All design tokens, fluid clamp typography, and component layouts are cleanly organized in modern CSS layers.
* 100% Mobile Responsive: Perfectly tuned for small mobile (320px) up to 4K ultrawide displays.
* Elementor Compatible: Full support for Elementor page builder, Elementor canvas, and header/footer locations without styling conflicts.
* Pre-built Block Patterns: Includes Hero Section, Ritual Intro & Product Cards, Everyday Wellness, 4-Step Preparation Ritual, Pure by Nature, Balance Showcase, From Leaf to Cup, Image Band, and Newsletter Call to Action.
* Accessible: WCAG 2.1 AA compliant with high-contrast color tokens, skip links, aria attributes, and keyboard navigation.
* Performance Focused: Pure vanilla JavaScript with zero external frameworks or jQuery dependencies.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes and click "Add New".
2. Click "Upload Theme" and select the aose-matcha theme zip file.
3. Click "Install Now" and then "Activate".
4. To edit the homepage, navigate to Appearance > Editor (Site Editor).

== Elementor Compatibility ==

AOSE Matcha is built to work seamlessly with Elementor and Elementor Pro:
* Elementor Page Templates: Supports Default, Elementor Full Width, and Elementor Canvas.
* No Style Conflicts: Theme CSS is scoped with CSS @layer and compatibility shields so Elementor widgets and column layouts retain their exact margins and paddings.
* Theme Builder: Supports custom Elementor headers and footers via standard theme locations.
